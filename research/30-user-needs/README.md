# 30-user-needs — what rescuers (and families) actually need

**Question:** What information problems do the people in this response actually have? Not "what can we build" — what do they *need*.

**Method:** Structured hypothesis document. Every need is tagged:

- `EVIDENCED` — with a source file reference
- `HYPOTHESIS` — plausible, needs validation with a real user before we act on it

**User classes** (information needs differ and sometimes conflict):

1. Helicopter crews / aerial recce
2. Ground SAR teams (Nepali Army, APF, Nepal Police)
3. Coordination cell / EOC (district + national)
4. Local volunteers & community responders
5. Families of the missing
6. Medical & body-recovery/identification teams

**Contents**

- `needs-hypotheses.md` — the needs register, per user class
- `priority-map-concept.md` — the team's initial three-layer priority-map idea, treated as a **hypothesis to test**, not a committed product. The gap analysis in `docs/DECISIONS.md` weighs it against alternatives (comms/coordination platforms, joining existing pipelines, advocacy).

**Status:** seeded 2026-08-29. Nothing in here is validated with an actual rescuer yet — that is Open Question #1.

# research/sources/

One file per source. Conventions: `docs/SOURCE_INGESTION.md`. Template: `_TEMPLATE.md`.

`LINKS_INDEX.md` is the running index of every link the team has collected, with ingestion status — check it before adding a file to avoid duplicates.

⚠️ If a source is itself a list of missing/dead individuals: record **metadata only**, never extract names or personal details.
